# 🌙 BEFORE ME, MOON

**An independent poetry collection by Mike Ramírez.**

*Before I could name the world, I named the moon.*

A collection of 75 poems exploring memory, identity, childhood, addiction, love, freedom, and the things we struggle to put into words.

Written from real experiences, unfinished thoughts, and handwritten notebooks. Raw, personal, and unapologetically human.
